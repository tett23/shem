# ADR 0007: PNG の書き出し、解像度、CLI の形

ステータス: 採択

## 文脈

Golem は shem をテストと CI からコマンドとして呼ぶ（[ADR 0001](0001-scope-golem-contract-and-determinism.md)）。
Golem の見た目の回帰テストは、PDF の全ページを画像にし、前のコミットの画像と比べる。
比べ方と参照の画像の置き場所は Golem の側で決めるが、shem はその材料として、ページごとの画像ファイルを出す必要がある。

画像の形式には PNG を使う。
ほとんどのビューアーとブラウザーで開け、差分を目で確かめやすいからである。
PNG の圧縮は Deflate で、[ADR 0001](0001-scope-golem-contract-and-determinism.md) の方針により自前で書く。
Deflate の出力のバイト列は、同じ画素でも、圧縮の手順を変えると変わる。
Golem が PNG のファイルをバイト列で比べるなら、shem の圧縮の手順の変更が、見た目の変化と区別できない差分になる。

## 実装すること

### CLI

```
shem render [--dpi <N>] [--format png|ppm] [--pages <範囲>] <入力の PDF> <出力のディレクトリ>
shem --version
shem --help
```

- `render` は、入力の PDF の各ページを描き、出力のディレクトリに一ページ一ファイルで書く。
- `--dpi <N>`：解像度。1 以上 1200 以下の整数とする。既定は 150 とする。
- `--format png|ppm`：出力の形式。既定は `png` とする。
- `--pages <範囲>`：描くページ。`3`、`2-5`、`1,3,5-7` の形とし、ページの番号は 1 から数える。既定はすべてのページ。範囲がページの数を超えたらエラーにする。
- オプションは、サブコマンドの後ろならどの位置に置いてもよい。同じオプションを二度書いたらエラーにする。
- `--version` は `shem <版>` を一行で出す。`--help` は、使い方、オプション、出力の形、終了コード、範囲の外の入力の扱い（[ADR 0002](0002-pdf-subset-and-out-of-scope-input.md)）を出す。

### 出力のファイル

- 出力のディレクトリがなければ作る（親のディレクトリも含めて作る）。
- ファイルの名前は `page-<番号>.<拡張子>` とする。番号は 1 から数え、ページの数の桁数と 4 のうち大きいほうの桁数に、0 で詰める（`page-0001.png`）。
- 同じ名前のファイルがあれば上書きする。ディレクトリのほかのファイルには触れない。
- ファイルは、一時的な名前（`.page-0001.png.tmp`）で書いてから、名前を変える。途中で止まったときに、書きかけのファイルを残さないためである。
- 描く前に、`--pages` のすべてのページを検査し（[ADR 0002](0002-pdf-subset-and-out-of-scope-input.md)）、範囲の外の入力があれば、ファイルを一つも書かずに終える。
- 標準出力には何も書かない。

### 画像の大きさ

- 画像の幅と高さは、`MediaBox` の幅と高さ（ポイント）に `dpi / 72` を掛け、切り上げた整数とする。計算は Q32.32 の値から整数の演算で行う（[ADR 0001](0001-scope-golem-contract-and-determinism.md)）。
- 幅か高さが 0 になる、または幅と高さの積が 2^28 を超えるときは、エラーにする。メモリーを使い尽くさないためである。
- 画素の位置の決め方は [ADR 0003](0003-paths-fill-stroke-and-antialiasing.md) による。

### PNG

- チャンクは `IHDR`、`IDAT`（一つ）、`IEND` だけを、この順に書く。時刻（`tIME`）、ガンマ（`gAMA`）、色空間（`sRGB`、`iCCP`）、解像度（`pHYs`）、文字（`tEXt`）などは書かない。
- `IHDR` は、ビットの深さ 8、色の型 2（RGB）、圧縮の方式 0、フィルタの方式 0、インターレースなし（0）とする。
- 行のフィルタは、行ごとに五つの型（None、Sub、Up、Average、Paeth）を試し、フィルタ後のバイトを符号つきの整数とみなした絶対値の和が最も小さいものを選ぶ。和が等しいときは、型の番号が小さいものを選ぶ。
- `IDAT` の中身は zlib の形式（RFC 1950）とし、Deflate（RFC 1951）で圧縮する。
  - LZ77 は、32 KiB の窓で、3 バイトのハッシュの鎖を使う。鎖をたどる数は 128 までとし、最も長い一致（等しければ最も近いもの）を選ぶ貪欲法とする。遅延の一致は使わない。
  - ハフマンの符号は固定の符号（BTYPE 1）だけを使う。ブロックは一つとする。
  - zlib のヘッダーは `78 01` とし、末尾に Adler-32 を置く。
- CRC-32 と Adler-32 は自前で書く。
- PNG のバイト列は、同じ版の shem で同じ画素なら同じになる。版が違えば、画素が同じでも、圧縮の手順の変更によりバイト列が変わることがある。圧縮の手順だけを変える版は、パッチバージョンを上げ、リリースノートに PNG のバイト列が変わることを書く。

### PPM

- `--format ppm` では、Netpbm の PPM（`P6`）を書く。ヘッダーは `P6\n<幅> <高さ>\n255\n` とし、その後に行の順、左から右の順で RGB の画素を並べる。
- PPM のバイト列は画素だけで決まり、版によらない。画素の比較を `cmp` でしたい利用者は PPM を使う。

### 終了コード

- 0：すべてのページを書いた。
- 1：入力が範囲の外か壊れている、または出力に失敗した。標準エラーにエラーを一行書く（[ADR 0002](0002-pdf-subset-and-out-of-scope-input.md)）。
- 64：コマンドの使い方が誤っている（未知のオプション、引数の数の誤り、範囲の外の `--dpi` など）。adr-guard と同じく、sysexits の `EX_USAGE` に合わせる。

## 実装しないこと

- 標準入力からの PDF の読み取りと、標準出力への画像の書き出し。
- 画像の比較、差分の画像の生成。比べ方は Golem の側の ADR で決める。
- 動的なハフマンの符号、遅延の一致など、圧縮の率を上げる工夫。ファイルの大きさが問題になったら、別の ADR で加える。
- `MediaBox` 以外の箱（`TrimBox`、`BleedBox`）で描く範囲を選ぶオプション。
- アルファのチャンネル、16 ビットの画素、灰色だけの画像。
- 並列の描画。

## テスト設計

### CLI

- `shem render in.pdf out` が `out/page-0001.png` からページの数だけファイルを書き、終了コードが 0、標準出力が空である。
- ページの数が 12345 の PDF（手で作る）では、名前が `page-00001.png` の五桁になる。
- `--pages 2-3` で二枚だけ書く。`--pages 0`、`--pages 3-2`、`--pages 99`（ページの数を超える）、`--pages x` はそれぞれエラーになる。
- `--dpi 0`、`--dpi 1201`、`--dpi 1.5`、`--format jpg`、`--dpi` の二度書き、未知のオプション、引数の不足は、終了コード 64 になる。
- 出力のディレクトリがないときは作られ、既存のファイルは上書きされ、関係のないファイルは残る。
- 範囲の外の入力では、出力のディレクトリにファイルが増えず、一時ファイルも残らない。
- `--version` が `shem 0.1.0` の形で出る。`--help` に、オプション、終了コード、範囲の外の扱いが含まれる。

### 画像の大きさ

- `MediaBox [0 0 362.8346 515.9055]`（Golem の sample の A5 に近い大きさ）を 150 dpi で描くと、幅 756、高さ 1075 になる（`362.8346 × 150 / 72 = 755.905…` と `515.9055 × 150 / 72 = 1074.80…` の切り上げ）。
- 幅と高さの積が 2^28 を超える `MediaBox` は、エラーになる。

### PNG

- 書いた PNG を、テストの中に自前で書いた検証で読み、シグネチャ、チャンクの順、`IHDR` の値、各チャンクの CRC-32 が正しいことを確かめる。
- `IDAT` を [ADR 0002](0002-pdf-subset-and-out-of-scope-input.md) の自前の伸長で戻し、フィルタを戻して、元の画素と一致することを確かめる。単色、横の縞、縦の縞、ランダムに近い模様（固定の種の線形合同法で作る）の画像で確かめる。
- フィルタの選び方：手で作った三行の画像で、各行に期待する型が選ばれる。
- Deflate：長さ 3 と 258、距離 1 と 32768 の一致が現れるデータを圧縮し、自前の伸長で戻る。
- CRC-32 と Adler-32：RFC 1950 と PNG の仕様にある計算の方法で、既知の値（`"123456789"` の CRC-32 が `CBF43926`、Adler-32 が `091E01DE`）になる。
- 外の実装との照合：CI の Linux の x86-64 で、fixture を PNG と PPM の両方で描き、apt で入れた `pngcheck` で PNG の構造と CRC を検査し、ImageMagick で PNG を PPM に変換したものが shem の PPM と `cmp` で一致することを確かめる。シェルのスクリプトとして `scripts/ci/check-png.sh` に置く。

### PPM

- `--format ppm` の出力が、ヘッダーと、PNG と同じ画素のバイト列になる。

## トレードオフ

- 固定のハフマンの符号だけにしたので、PNG は大きめになる。ページの多くは白で、LZ77 の長い一致が効くので、固定の符号でも十分に小さくなると見込む。
- PNG のバイト列を版をまたいで固定しないので、Golem が PNG をバイト列で比べると、shem の版を上げたときに、画素の変わらない差分が出うる。PPM を出せるようにしたので、Golem はバイト列で比べるなら PPM を、画像を見るなら PNG を選べる。
- 一時的な名前で書いてから名前を変えるので、出力のディレクトリには書き込みと名前の変更の権限が要る。
- `--dpi` を整数に限るので、72 の倍数でない解像度では `dpi / 72` が割り切れない。Q32.32 で表すので、決定性は保たれる。
- 外の実装との照合に pngcheck と ImageMagick を使うので、CI でだけ apt の依存が増える。shem の実行ファイルの依存は増えない。
