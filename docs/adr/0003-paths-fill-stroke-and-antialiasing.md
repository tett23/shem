# ADR 0003: パスの変換、塗り、線、アンチエイリアス

ステータス: 採択（未実装）

## 文脈

[ADR 0002](0002-pdf-subset-and-out-of-scope-input.md) で、v0.1 が解釈する演算子をページの内容のものに限った。
そのうちパスに関わるのは `m c h re f w q Q cm` である。
ページの内容には、切り抜き（`W`）も線の描画（`S`）もない。
線を描くのは、合成の太字（`2 Tr`）でグリフの輪郭をなぞるときだけで、そのときの線端と角は既定値（`0 J`、`0 j`、`10 M`）のままである（Golem の origin/main 1254092a の [Writer.hs:236-285](https://github.com/tett23/golem/blob/1254092a2ed5a7fd29bb6f1affb53806cf76c694/modules/golem-pdf/src/Golem/Pdf/Writer.hs#L236-L285)）。
画像と Form の箱（[ADR 0006](0006-placeholder-boxes-for-images-and-forms.md)）も、塗りと線で描く。

[ADR 0001](0001-scope-golem-contract-and-determinism.md) で、描画は整数と固定小数点の演算だけで行うと決めた。
この ADR は、パスを画素にするまでの計算を、浮動小数点数を使わずに決める。
アンチエイリアスの方式には、FreeType の灰色のラスタライザ（`ftgrays.c`）の方式を採る。
セルごとに覆う面積を整数で積む方式で、浮動小数点数を使わずに書け、広く使われているからである。

## 実装すること

### 座標系

- 装置の空間は、左上を原点とし、x を右、y を下に向ける。画素 (i, j) は、[i, i+1] × [j, j+1] の正方形を占める。
- 解像度 `dpi`（[ADR 0007](0007-png-output-resolution-and-cli.md)）と `MediaBox` の `[llx lly urx ury]` から、既定の利用者の空間から装置の空間への行列を `D = [s 0 0 −s −s·llx s·ury]` とする。`s = dpi / 72` を Q32.32 で表す。
- ページの初期の CTM は `D` とし、`cm` の行列 `M` で `CTM ← M × CTM` にする（ISO 32000-1 の 8.3.4、8.4.4）。
- `MediaBox` の座標が逆順（`llx > urx` など）なら、正規化する（ISO 32000-1 の 7.9.5）。

### パスの構築

- `m`、`c`、`h`、`re` で、利用者の空間のパスを作る。点は、作るときに CTM で装置の空間に写し、画素の 1/256 を単位とする整数に丸める（最近接の偶数への丸め）。
- `re x y w h` は、`x y m`、`(x+w) y l`、`(x+w) (y+h) l`、`x (y+h) l`、`h` と同じとする（ISO 32000-1 の 8.5.2.1）。
- `h` は、現在の部分パスを閉じる。`f` は、閉じていない部分パスも閉じたものとして塗る。
- `f` の後、パスを空にする。

### 曲線の平坦化

- 3 次のベジエ曲線は、装置の空間の整数の座標で、ド・カステリョの方法で中点で二分し、線分の列にする。
- 中点は、二つの点の座標の和を 2 で割り、負の無限大の方向に丸める（算術右シフト）。
- 制御点 p0、p1、p2、p3 について、`d = max(|p0 − 2p1 + p2|∞, |p1 − 2p2 + p3|∞)` が 1/16 画素（16 単位）以下になるまで分ける。分ける深さは 16 までとし、16 に達したらそこで止める。
- 同じ曲線は、どの機械でも同じ線分の列になる。

### 塗り

- 塗りの規則は nonzero とする（`f`）。偶奇の規則（`f*`）は、図版を描くときに使うので、同じラスタライザで選べるようにしておく。
- ラスタライザは ftgrays と同じ方式とする。
  - 各線分を画素のセルに分け、セルごとに、セルの左の辺を横切る符号つきの高さ（cover）と、セルの中で線分の左にある符号つきの面積（area）を、整数で積む。
  - 各行で、セルを x の順に並べて cover を左から累積し、各画素の符号つきの覆いを求める。
  - 覆いの絶対値を、nonzero なら 1 で上限を切り、偶奇なら 2 を法として畳む。
  - 覆いを 0 から 255 の不透明度にする。覆いの単位を `ONE` として、`(v × 255 + ONE/2) / ONE` とする（整数の除算）。
- セルは行ごとに x の順に並べる。並べ方は値だけで決まり、挿入の順によらない。

### 合成

- ページは、白（RGB の 255、255、255）で初期化する。
- 塗る色（[ADR 0005](0005-device-colors-and-cmyk-conversion.md)）の各チャンネル `c` と、画素の不透明度 `a` について、画素の値 `p` を `(c × a + p × (255 − a) + 127) / 255` にする（整数の除算）。
- 塗りの演算子ごとに、パス全体の覆いを求めてから一度だけ合成する。同じ画素に重なる部分パスを二度合成しない。

### 線

線は、合成の太字（`2 Tr`）と、画像と Form の箱の対角線（[ADR 0006](0006-placeholder-boxes-for-images-and-forms.md)）で使う。

- 線端は butt（`0 J`）、角は miter（`0 j`）、miter の上限は 10（`10 M`）とする。v0.1 では、これらを変える演算子（`J`、`j`、`M`）も、破線（`d`）も解釈しない（[ADR 0002](0002-pdf-subset-and-out-of-scope-input.md)）。
- 線の幅は、利用者の空間の値 `w` に CTM の拡大率を掛けて装置の空間の幅にする。拡大率は `sqrt(|det CTM|)` とし、平方根は 128 ビットの整数の平方根（切り捨て）で求める。
- 線を描くときの CTM は、角を保つもの（`a = d` かつ `b = −c`、または `a = −d` かつ `b = c`）に限る。そうでなければエラーにする。角を保たない CTM の線は楕円のペンになり、v0.1 の範囲の外だからである。ページの内容の CTM は、`D` に平行移動と 90° の回転を掛けたものなので、この条件を満たす。
- 画像と Form の箱の対角線（[ADR 0006](0006-placeholder-boxes-for-images-and-forms.md)）は、装置の空間で幅を決めて描くので、この条件を受けない。箱を描くときの CTM は `w 0 0 h x y cm` を含み、角を保たないからである。
- 線の幅が 0 なら、装置の空間で 1 画素の幅とする（ISO 32000-1 の 8.4.3.2）。
- 線は、平坦化した線分の列について、次の多角形の和として作り、nonzero で塗る。
  - 各線分の両側に幅の半分だけずらした四角形
  - 部分パスの中の隣り合う線分の継ぎ目の、外側の三角形（bevel）と、miter の上限に収まるときの miter の先端
  - 閉じた部分パスでは、最後の線分と最初の線分の継ぎ目
- 各多角形は、符号つきの面積が正になる向きにそろえる。向きがそろっていれば、nonzero の塗りが和集合になる。
- 法線の向きの単位ベクトルは、線分の方向を整数の平方根で割って求める。長さ 0 の線分は捨てる。
- miter の上限の判定では、入る線分と出る線分の単位ベクトルを u1、u2 とし、二つの線分のなす角 φ を `cos φ = −(u1 · u2)` で表す。miter の長さの比 `1 / sin(φ/2)` が 10 以下であることは `(1 − cos φ) × 10² ≥ 2` と同じなので、これを固定小数点のまま判定する（ISO 32000-1 の 8.4.3.5）。

## 実装しないこと

- 切り抜き（`W`、`W*`）。ページの内容に現れない。描く範囲はページの全体である。
- 線端の round と square、角の round と bevel の指定、破線。図版を描くときに別の ADR で加える。
- 角を保たない CTM での線。
- 自動の stroke adjustment（ISO 32000-1 の 10.6.5）。
- 透明、ブレンドのモード、オーバープリント。
- アンチエイリアスを切るオプション。

## テスト設計

### 平坦化

- 直線と同じ形の曲線（制御点が線分の上にある）は、1 本の線分になる。
- 半円に近い曲線を平坦化した点が、真の曲線から 1/16 画素より離れない（真の曲線の点は、テストの中で有理数の計算で求める）。
- 退化した曲線（四点が同じ）でも止まり、深さが 16 を超えない。

### 塗り

- 画素の格子に合った 10 × 10 画素の正方形を塗ると、中は 255、外は 0 の覆いになる。
- 半画素ずれた正方形は、辺の画素が 128 前後になり、四隅が 64 前後になる。厳密な値をゴールデンとして固定する。
- 同じ向きに二重に重なる正方形を nonzero で塗ると、一重のときと同じ覆いになる。逆向きに重なる正方形は、重なりが穴になる。
- 偶奇の規則では、同じ向きに重なる正方形の重なりが穴になる。
- 合成：不透明度 255 で色に、0 で元の値に、128 で式どおりの値になる。

### 線

- 水平の線分を幅 2 画素で描くと、上下に 1 画素ずつの帯になり、端は線分の端で切れる（butt）。
- 直角に曲がる折れ線の外側の角が、miter で尖る。
- 角度の小さい折れ線（miter の比が 10 を超える）は、bevel になる。
- 閉じた正方形の始点の角も、ほかの角と同じ形になる。
- 幅 0 の線は 1 画素の幅になる。
- 角を保たない CTM（`cm 2 0 0 1 0 0` の後の `2 Tr`）は、エラーになる。

### ページ

- `MediaBox [0 0 72 72]` を 72 dpi で描くと、`0 0 36 36 re f` が左下の 36 × 36 画素を塗る（y の反転）。
- Golem の出力の fixture のゴールデンを、x86-64 と aarch64、Linux と macOS で一致させる（[ADR 0001](0001-scope-golem-contract-and-determinism.md)）。

## トレードオフ

- 曲線の平坦化の許容誤差を 1/16 画素にした。画素の値の差はアンチエイリアスの量子化（1/255）と同じ程度で、見た目の変化の検出に足りる。細かくすると線分が増え、遅くなる。
- ftgrays の方式は、同じ画素の中で辺が交わるときに、覆いを近似で求める。正確な面積ではないが、決まった計算なので結果は揺れない。正確な面積の計算（多角形の切り抜き）は、遅く、実装も重い。
- 線を多角形の和として作る方式は、線の輪郭を一本のパスにまとめる方式（FreeType の stroker など）より単純で、自己交差の扱いを nonzero に任せられる。そのかわり、多角形の数が増える。
- 継ぎ目の判定で、曲線を平坦化した線分の間にも miter を使う。PDF の規格では、曲線の内部に角はない。平坦化の線分の間の角度は小さく、miter の先端は線の幅の誤差の範囲に収まるので、見た目は変わらない。
- 色の合成を 8 ビットの RGB の空間で、ガンマを考えずに行う。正しい合成ではないが、比較の目的には足り、整数で単純に書ける。
