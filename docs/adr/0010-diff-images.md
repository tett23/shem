# ADR 0010: 画像の差分の画像を出す（ファイルどうしとディレクトリどうし）

ステータス: 採択（未実装）

## 文脈

Golem の見た目の回帰テストは、前のコミットの画像と今の画像を比べ、違えば失敗する。
比べ方と、失敗を判定する規則は Golem の側で決める（[ADR 0007](0007-png-output-resolution-and-cli.md) で、画像の比較と差分の画像の生成を shem の「実装しないこと」に入れた）。

テストが失敗したとき、人は二枚の画像を見比べて、意図した変更か、壊れたのかを判断する。
変わったのが数画素（字の位置の 1 画素のずれ、ルビの一字など）だと、二枚を並べても見つけにくい。
違う画素に色を付けた一枚の画像があれば、どこが変わったかがすぐにわかる。

Golem が比べるのは、書籍の全ページである。
`shem render` は一ページを一ファイルにしてディレクトリに書くので（[ADR 0007](0007-png-output-resolution-and-cli.md)）、前と今の二つのディレクトリができる。
ページごとに利用者がコマンドを呼ぶと、ページの対応づけ、増えたページと減ったページの扱い、並列化を、利用者がそれぞれ書くことになる。
メンテナーは、ディレクトリどうしを比べたいと判断し、一枚どうしの比較も残すと決めた（2026-10-27）。

この画像を作るのに要るのは、shem が書く形の画像を読み、画素を比べ、色を付けて書くことだけである。
PNG の書き出し、Flate の伸長、CRC-32 はすでに自前で持っている（[src/png.rs](https://github.com/tett23/shem/blob/702584ad2fa0137d94786b0a6b03c895af86e007/src/png.rs)、[src/flate.rs](https://github.com/tett23/shem/blob/702584ad2fa0137d94786b0a6b03c895af86e007/src/flate.rs)）。
差分の画像も、ほかの出力と同じく、どの機械でも同じバイト列になるように作れる。

差分を取る相手には、画像と PDF の二つの案がある。
Golem は参照の画像を持っておき、新しい画像と比べる。
参照の画像を作った版の PDF は、手元に残っているとは限らない。
画像どうしの差分なら、どの版の shem が描いた画像でも比べられ、PDF を描く処理とも独立する。
そこで、画像どうしの差分を取る道具にする。

## 実装すること

### コマンド

```
shem diff [--format png|ppm] [--jobs <N>] <前> <後> <出力>
```

- `<前>` と `<後>` がどちらもファイルなら、二枚の画像を比べる（ファイルの比較）。`<出力>` は差分の画像のファイルのパスとする。
- `<前>` と `<後>` がどちらもディレクトリなら、中の画像をページごとに比べる（ディレクトリの比較）。`<出力>` は差分の画像を書くディレクトリとする。
- 片方がファイルでもう片方がディレクトリなら、使い方の誤りとする。
- `--format` は差分の画像の形式で、既定は `png` とする。入力の形式は、ファイルの先頭のバイトで判定する。
- `--jobs` はディレクトリの比較で同時に比べるページの数の上限で、意味、既定値、範囲は `shem render` の `--jobs`（[ADR 0009](0009-render-pages-in-parallel.md)）と同じとする。ファイルの比較では、受け付けるが効果はない。
- オプションは `diff` の後ろならどこに置いてもよい。二度の指定と未知のオプションは使い方の誤りとする。
- 差分の画像は、[ADR 0007](0007-png-output-resolution-and-cli.md) と同じく一時的な名前で書いてから名前を変える。

### ファイルの比較

- 二枚が同じ（大きさも画素も同じ）なら、差分の画像は書かず、標準出力にも何も書かない。`<出力>` にすでにあるファイルには触れない。
- 違えば、差分の画像を `<出力>` に書き、標準出力に次の一行を書く。
  ```
  differ: <違う画素の数> pixels in <x0> <y0> <x1> <y1>
  ```
  `x0 y0` は違う画素を囲む最小の矩形の左上（含む）、`x1 y1` は右下（含まない）で、画素の単位とする。
- `<出力>` のディレクトリは作らない。なければエラーにする。

### ディレクトリの比較

- 比べるのは、各ディレクトリの直下にある通常のファイルのうち、名前が `.png` か `.ppm` で終わり、`.` で始まらないものとする。サブディレクトリとほかのファイルは読まない。`shem render` の一時ファイル（`.page-0001.png.tmp`）も対象にならない。
- ページは、ファイルの名前が同じもの同士で対応させる。
- 対応するファイルの組ごとに、ファイルの比較と同じ規則で比べる。違う組だけ、差分の画像を `<出力>/<拡張子を除いた名前>.<png|ppm>` に書く（`page-0003.png` と `page-0003.png` の差分は、`--format png` なら `<出力>/page-0003.png`）。
- 片方のディレクトリにしかないファイルは、差分の画像を作らず、報告だけをする。
- `<出力>` のディレクトリがなければ、親を含めて作る。同じ名前のファイルは置き換え、ほかのファイルには触れない。前の実行の差分の画像が残っていても消さない。
- 標準出力には、違う組と片方にしかないファイルを、ファイルの名前のバイト列の順で一行ずつ書く。
  ```
  differ: page-0003.png: 120 pixels in 10 20 110 80
  added: page-0010.png
  removed: page-0009.png
  ```
  `added` は後のディレクトリにだけあるファイル、`removed` は前のディレクトリにだけあるファイルとする。同じ組は書かない。
- 組は [ADR 0009](0009-render-pages-in-parallel.md) と同じ仕組みで並列に比べる。標準出力の行は、すべての組の結果がそろってから名前の順で書くので、`--jobs` と終わった順によらず同じになる。
- 読めない組があれば、まだ比べ始めていない組は比べない。名前の順で最初のエラーを報告する。それまでに書いた差分の画像は残る。

### 終了コード

`cmp` と `diff` の慣習に合わせ、ファイルの比較とディレクトリの比較で同じとする。
`shem render` の終了コード（[ADR 0007](0007-png-output-resolution-and-cli.md)）は変えない。

- 0：違いがない（ディレクトリの比較では、ファイルの名前の集合も同じで、すべての組が同じ）。
- 1：違いがある（違う組か、片方にしかないファイルがある）。
- 2：入力を読めない、範囲の外の形式である、出力に失敗した。標準エラーに `shem: <パス>: <内容>` を一行書く。
- 64：使い方の誤り。

### 読む画像の形式

shem が書く形だけを読む。それ以外はエラー（終了コード 2）とする。

- **PNG**：シグネチャ、`IHDR` が 8 ビットの RGB（色の型 2）、圧縮の方式 0、フィルタの方式 0、インターレースなし。`IDAT` は一つ以上で、つないで zlib として伸長する（[ADR 0002](0002-pdf-subset-and-out-of-scope-input.md) の自前の伸長）。各チャンクの CRC-32 を確かめる。補助のチャンク（種類の最初の文字が小文字のもの）は読み飛ばす。`PLTE` などほかの必須のチャンク、ほかの色の型とビットの深さ、インターレースはエラーにする。五つのフィルタの型を戻す。
- **PPM**：`P6`、幅、高さ、最大値 255 のヘッダーと、その後の画素。ヘッダーの区切りの空白とコメント（`#` から行末まで）は Netpbm の規則のとおりに読む。最大値が 255 でないものはエラーにする。
- 画素の数が 2^28 を超える画像はエラーにする（[ADR 0007](0007-png-output-resolution-and-cli.md) の上限と同じ）。

### 差分の画像

整数だけで計算する（[ADR 0001](0001-scope-golem-contract-and-determinism.md)）。

- 大きさは、二枚の幅の大きいほうと、高さの大きいほうとする。
- 明るさは `L = (299 R + 587 G + 114 B + 500) / 1000`（整数の除算、ITU-R BT.601 の係数）とする。
- 各画素を、次の順に決める。

| 画素 | 色 |
|---|---|
| 片方の画像にしかない（大きさが違うときのはみ出し） | 緑 `(0, 160, 0)` |
| 違い、後のほうが暗い（インクが増えた） | 赤 `(230, 0, 0)` |
| 違い、後のほうが明るい（インクが減った） | 青 `(0, 90, 255)` |
| 違い、明るさが同じ（色だけが変わった） | 紫 `(180, 0, 180)` |
| 同じ | 後の画像の明るさ `L` を薄めた灰色 `255 − (255 − L) / 4` |

- 違う画素を囲む最小の矩形を、各辺から 3 画素外に広げた位置に、幅 2 画素の橙 `(255, 160, 0)` の枠を描く。枠は「同じ」の画素の上にだけ描き、違う画素の色は消さない。枠は画像の縁で切れる。数画素の変化でも、枠で場所がわかるようにするためである。
- 「違う」は、三つのチャンネルのどれかが違うことをいう。しきい値は設けない。shem の出力は決定的なので、一つの値の違いにも意味がある。

## 実装しないこと

- 合否の判定の規則（許す画素の数、しきい値など）。判定は Golem の側で、終了コードか画像のバイト列の比較で行う。
- 名前の違うファイルどうしの対応づけ（`page-0001.png` と `page-00001.png`、`page-0001.png` と `page-0001.ppm` など）。ページの数が 9999 を超えて桁が変わったときは、すべてのページが `added` と `removed` になる。
- サブディレクトリをたどる比較。
- 増えたページと減ったページの画像を作ること。それらのページは、元の画像をそのまま見ればよい。
- 出力のディレクトリに残った古い差分の画像を消すこと。
- 二つの PDF を描いて比べるサブコマンド。
- 二枚を左右に並べた画像、変化した部分の拡大、アニメーション、一覧の HTML。
- 違う画素の塊ごとの枠。枠は全体を囲む一つだけとする。
- shem が書かない形の画像（8 ビット RGB 以外の PNG、インターレース、パレット、16 ビット、PGM など）。

## テスト設計

### 画素の色（ファイルの比較）

小さな画像を PPM でテストの中に作り、`shem diff` で確かめる。

- 同じ二枚：終了コード 0、標準出力は空、出力のファイルはできない。既存の出力のファイルは変わらない。
- 一画素だけ後のほうが暗い：終了コード 1、標準出力が `differ: 1 pixels in x y x+1 y+1`、その画素が赤、ほかの画素が薄めた灰色、枠が式どおりの位置に橙で描かれる。
- 一画素だけ後のほうが明るい：その画素が青。
- 明るさが同じで色だけが違う二色（テストの中で、明るさの式が同じ値になる二色を探して使う）：その画素が紫。
- 幅が違う二枚：出力の幅は大きいほうで、はみ出しの列が緑。
- 違う画素が画像の縁にあるとき、枠が縁で切れても描画が止まらない。
- 枠は違う画素の上に描かれない。
- 出力のディレクトリがないときは終了コード 2 になり、一時ファイルが残らない。

### ディレクトリの比較

- 同じ画像を持つ二つのディレクトリ：終了コード 0、標準出力は空、出力のディレクトリにファイルができない。
- 前に `page-0001.png`〜`page-0003.png`、後に `page-0001.png`、`page-0002.png`（違う画像）、`page-0004.png` を置く：終了コード 1、標準出力が `differ: page-0002.png: ...`、`removed: page-0003.png`、`added: page-0004.png` の三行で、この順に並ぶ。出力のディレクトリには `page-0002.png` だけができる。
- PNG と PPM が同じ名前で対応しないこと：前の `page-0001.png` と後の `page-0001.ppm` は、`removed` と `added` になる。
- `.` で始まるファイル、`.txt` のファイル、サブディレクトリは無視される。
- 出力のディレクトリがなければ作られる。既存の関係のないファイルは残る。
- 12 組のうち 6 組が違う二つのディレクトリを、`--jobs 1` と `--jobs 8` で比べ、標準出力と書いた差分の画像のバイト列が同じであることを確かめる。これを 20 回繰り返して、毎回同じであることを確かめる。
- 読めない組が二つあるとき（壊れた PNG）、`--jobs 1` でも `--jobs 8` でも、報告が名前の順で最初の組のエラーで、終了コードが 2 になる。
- 片方がファイルでもう片方がディレクトリなら、終了コード 64 になる。

### 読み取り

- shem が書いた PNG と PPM：Golem の fixture のゴールデン（[ADR 0001](0001-scope-golem-contract-and-determinism.md)）のすべての PNG を読み、同じページを PPM で描いたものと同じ画素になる。
- PNG と PPM を混ぜた二枚も、ファイルの比較で比べられる。
- `IDAT` を二つに分けた PNG、補助のチャンク（`tEXt`）を含む PNG は読める。
- 色の型 6、ビットの深さ 16、インターレース、`PLTE` を含む PNG、CRC の誤り、壊れた zlib、P3（テキストの PPM）、最大値 65535 の PPM、途中で切れたファイルは、終了コード 2 になる。
- PPM のヘッダーのコメントと、改行以外の空白の区切りを読める。

### 決定性

- `sample` の 1 ページ目と `sample-marks` の 1 ページ目（塗り足しで大きさも違う）の差分の画像を、ゴールデンとして置く。CI の三つの環境で、バイト単位で一致することを確かめる。

### コマンド

- 引数の不足、未知のオプション、`--format jpg`、`--format` の二度の指定、`--jobs 0` は、終了コード 64 になる。
- `--help` に `diff`、ファイルの比較とディレクトリの比較、終了コードの説明が含まれる。

### 目で確かめること

- Golem の fixture の一字を変えた PDF を作って描き、ディレクトリの比較の差分の画像で、変わった字の場所がすぐにわかることを、メンテナーが確かめる。この項目を [docs/roadmap.md](../roadmap.md) の「目視検査の項目」に加える。

## トレードオフ

- 画像どうしの差分にしたので、PDF を描く処理と独立し、どの版の shem で描いた画像でも比べられる。そのかわり、利用者は先に画像を描いておく必要がある。
- ファイルの比較とディレクトリの比較を一つのサブコマンドにし、入力がファイルかディレクトリかで分けた。二つのサブコマンドに分けると名前が増え、規則（色、終了コード、読む形式）を二か所で説明することになる。そのかわり、引数の種類で振る舞いが変わるので、片方だけがディレクトリの誤りを使い方の誤りとして明示的に拒む。
- ページの対応を同じ名前に限ったので、規則は単純で予想しやすい。そのかわり、名前の付け方が変わると（桁数、拡張子）、すべてのページが増えたページと減ったページになる。`shem render` で同じ形式と同じページの数の範囲で描けば、名前はそろう。
- 増えたページと減ったページの画像を作らないので、出力のディレクトリには違うページの差分だけが並ぶ。人は、報告の行を見て元の画像を開く。
- 出力のディレクトリの古い差分の画像を消さないので、前の実行の結果が混ざりうる。消すと、利用者が同じディレクトリに置いたほかのファイルを消すおそれがある。毎回空のディレクトリに書く運用を、利用者の側で選べる。
- 読む画像を shem が書く形に限ったので、PNG の読み取りは小さく済む。ほかの道具で編集した画像は比べられない。範囲の外でエラーにする原則（[ADR 0002](0002-pdf-subset-and-out-of-scope-input.md)）と同じ考え方である。
- しきい値を設けないので、アンチエイリアスの値が一つ変わっただけの画素にも色が付く。shem の出力は機械によらず同じなので、その違いは実際の変化から来ている。
- 色の付け方を、明るさの増減で赤と青に分けた。字が増えたか消えたかを、色で区別できる。増減の二色は、色覚の多様性で区別しにくい赤と緑の組み合わせにしなかった。はみ出しの緑は赤と同じ画像に現れうるが、画像の端の帯として現れるので、位置でも区別できる。
- 差分の画像の色や枠を変えると出力のバイト列が変わる。差分の画像は人が見るためのもので、合否の判定には使わないので、変えたらパッチバージョンでよいとする。
- 終了コードを `render` と変えた（`diff` は 1 が「違う」、2 が「エラー」）。`cmp` や `diff` と同じ慣習で、スクリプトから使いやすい。そのかわり、サブコマンドごとに意味が変わるので、`--help` に両方を書く。
