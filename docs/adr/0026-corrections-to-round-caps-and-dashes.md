# ADR 0026: 丸い線端と破線の決まりの修正（円板の作り方、終点の点、奇数の配列の周期、テストの許容幅）

ステータス: 採択（未実装）

## 文脈

[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) は、ページのパスの線（`l`、`S`）と、丸い線端（`J`）と破線（`d`）を読むと決めた。
その実装（2026-11-10、Fable のエージェントによる）の途中で、[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) の決まりとテスト設計に、そのままでは満たせないものと、決めていないものが見つかった。

### 円板の対称性

[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) は、円板を「原点を中心とする四つの四分円の 3 次のベジエ曲線を、平坦化で線分の列にした多角形」とし、テスト設計で「点の集合が軸と対角線で反転して等しい」ことを求める。
平坦化の二分は、中点を右への算術シフト（`>> 1`）で求める。
算術シフトは負の数を負の無限大の向きに丸めるので、x や y が負の四分円では、正の四分円と丸めの向きが逆になる。
四つの四分円を別々に平坦化すると、点の集合は軸で反転して等しくならない。

### 円板の点の誤差

[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) のテスト設計は、半径 1 から 2^20 単位で、円板のすべての点の中心からの距離が `half` から「1/16 画素と 2 単位」以内であることを求める。
四つの 3 次のベジエ曲線で円を近似すると、曲線そのものが円から外れる。
制御点の距離を [ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) の `36195 / 65536` とした四分円を、t を 10 万等分して浮動小数点数で調べると（2026-11-10、手元の一時的なスクリプト）、外れは最大で半径の 0.02742% だった。
実装で測ると、外れは `half = 128` で 1 単位、4096 で 3 単位、65536 で 15 単位、2^20 で 285 単位だった。
1/16 画素は 16 単位なので、`half` が 2^16 を超えると、決まりのとおりに作った円板がテストを満たさない。
誤差は曲線の近似によるもので、平坦化や丸めの誤りではない。

### 部分パスの終点の、長さ 0 の破線

[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) は、「長さ 0 の『描く』要素は、`1 J` なら、その位置の円板になる」とだけ決め、部分パスの終点にちょうど重なる要素を区別しない。
pdftoppm（poppler-utils 26.09.0）は、開いた部分パスの終点にちょうど重なる長さ 0 の要素を描かない。
手元で、`4 w 1 J [0 12] 0 d` で長さ 36 ポイントの水平の線分を 72 dpi で描き、x = 10、22、34 の三つの点が描かれ、終点の x = 46 の点が描かれないことを確かめた（2026-11-10）。
始点と、途中の頂点に重なる要素は描かれる。
Golem の点線の枠で `border-sides` が辺を途切れさせると、開いた部分パスの長さが周期の倍数になり、終点に点が重なる。
ここで点を描くか描かないかで、pdftoppm との目視の比べ方（[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) のテスト設計）の結果が変わる。
閉じた部分パスでは、終点は始点と同じ位置なので、終点に重なる点は始点の点とちょうど重なる。
そのため、pdftoppm がその点を描くかどうかは、画素からは見分けられない。

### 奇数の配列の周期

[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) は、奇数の要素の配列を「二回つないだものとして扱う」と決め、別の項で「配列の和（周期）」が 1/16 画素未満ならエラーにすると決めた。
奇数の配列で、周期が元の配列の和か、二回つないだ配列の和かを決めていない。

### `d` の被演算子の誤りの文

[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) は、配列の要素の負の数と数でない要素、負の位相を「エラーにする」とし、文を決めていない。

### 破線の長さの和の許容幅

[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) のテスト設計は、乱数の折れ線で、破線の区間の長さの和が参照と「線分の数の 2 倍の単位以内」で一致することを求める。
破線の区間の端点は、距離 t の点を装置の単位（1/256 画素）の整数に丸める。
区間の長さは丸めた端点から測るので、区間ごとに、両端の丸めの分（破線の長さの単位で 2^17 まで）ずれうる。
この丸めは、線分の数ではなく区間の数に比例するので、決めた許容幅では足りない。

## 実装すること

### 円板の作り方

- 円板は、第一象限の四分円（(half, 0) から (0, half)、制御点の距離 `k` は [ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) のとおり）だけを平坦化し、その点の列を y 軸、原点、x 軸で反転して、四つの四分円をつないだ多角形とする。
- 点の集合は、軸と対角線での反転で等しい。曲線と平坦化の決まり（中点での二分、1/16 画素、深さ 16）は、[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) と同じである。

### 部分パスの終点の点

- 部分パスの終点にちょうど重なる長さ 0 の「描く」要素は、描かない。開いた部分パスでは、pdftoppm と同じ振る舞いである。
- 閉じた部分パスでも同じく、始点に戻る位置にちょうど重なる長さ 0 の要素は描かない。その位置には、始点の要素が描かれる。
- 始点と、途中の頂点に重なる長さ 0 の要素は、[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) のとおり描く。

### 奇数の配列の周期

- 奇数の要素の配列の周期は、二回つないだ配列の和（元の配列の和の 2 倍）とする。位相はこの周期で割った余りにし、1/16 画素の下限もこの周期に当てる。

### `d` の被演算子の誤りの文

- 配列の要素の負の数と数でない要素、負の位相は、`w` の負の値と同じく `wrong operands of d` のエラーにする。
- 空でない配列の要素がすべて 0 なら、[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) のとおり `malformed d` のエラーにする。

### 文書

- 仕様の「描画」の線の項に、円板の作り方（反転）、終点の点、奇数の配列の周期を書き、この ADR へのリンクを付ける。
- [ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) のステータスを「採択→円板の作り方、終点の点、奇数の配列の周期、テストの許容幅はADR 0026」にする。

## 実装しないこと

- 円を近似する曲線を、4 本より多いベジエ曲線や、整数の円の描き方に変えること。0.0274% の外れは、`half` が約 58,000 単位（228 画素）を超える太い線でしか 1/16 画素を超えず、Golem の枠の太さでは見えない。
- 閉じた部分パスの終点の点を、始点の点に重ねて描くこと。始点の点と同じ位置の同じ円板を、二度描くことになる。

## テスト設計

[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) のテスト設計のうち、次のものを置き換える。

- 円板の点：半径 1 から 2^20 単位の乱数で、すべての点の中心からの距離が、`half` から `16 + 2 + ceil(half · 18 / 65536)` 単位以内である。`18 / 65536`（0.02747%）は、曲線の近似の外れ 0.02742% を上から抑える値である。点の数は 4 の倍数で、点の集合が軸と対角線で反転して等しい。
- 破線の長さの和：乱数の折れ線で、区間の長さの和が参照と、`2 · 線分の数 + 2^17 · 区間の数` 単位以内で一致する。区間の端点が参照と 2 単位以内で一致することは、[ADR 0025](0025-strokes-of-paths-with-round-caps-and-dashes.md) のとおりとする。
- 周期の下限：偶数の配列で、周期が 1/16 画素ちょうどなら通り、1 単位短いとエラーになる。奇数の配列では、周期が 2 単位ずつ変わるので、ちょうどなら通り、2 単位短いとエラーになる。72 dpi と 300 dpi で境目が変わることも確かめる。

次のテストを足す。

- `1 J [0 12] 0 d` で長さ 36 ポイントの開いた線分を描くと、点は始点から 12 ポイントごとの三つで、終点には描かない。直角に曲がる開いた折れ線では、頂点の点は描き、終点の点は描かない。
- 一辺 12 ポイントの正方形を `h` で閉じると、点は四つの角の四つで、始点に戻る位置には描かない。
- `[3] 0 d` の周期は 6 で、位相 7 は位相 1 と同じ画像になる。
- `[-1 2] 0 d`、`[/a] 0 d`、`[3 2] -1 d` のエラーの文が `wrong operands of d` である。

## トレードオフ

- 円板を反転で作るので、四つの四分円を別々に平坦化する場合と点が違う。どちらも同じ曲線の平坦化で、違いは丸めの向きだけである。反転で作れば、点の集合が対称になり、円板の向きによって線端の形が変わらない。
- 終点の点を描かない決まりは、ISO 32000-1 には書かれていない。開いた部分パスでは pdftoppm に合わせたので、ほかの描画系（Acrobat や pdf.js）と合うかは確かめていない。閉じた部分パスで pdftoppm が始点に戻る位置の点を描くかは、画素から見分けられないので確かめていない。
- テストの許容幅を、決まりのとおりに作った円板と破線に合わせて広げた。広げた分は、曲線の近似と端点の丸めで説明でき、実装の誤りを見逃す幅ではない。
